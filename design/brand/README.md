# HouseCairn brand kit

Source files of the logo. The web interface serves copies from
`src/housecairn/static/img/brand/` (icon, wordmark, favicons, home-screen icons).

| File | Use |
| --- | --- |
| `housecairn-logo.svg` | Wordmark on a light background (headers, README) |
| `housecairn-logo-noir.svg` | One-colour dark wordmark |
| `housecairn-logo-blanc.svg` | One-colour white wordmark |
| `housecairn-logo-fond-sombre.svg` | Wordmark for dark backgrounds |
| `housecairn-icone.svg` | Cairn icon, transparent background |
| `housecairn-icone-app.svg` | Application icon (rounded square, slate background) |

Palette: slate `#1F3A3D`, sand `#C8A27C`, sage `#8FA39A`, stone `#5F726E` (same
values as `design/tokens.json`).
