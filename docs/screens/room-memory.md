# Room memory

What you can no longer see once the work is finished, at
`/h/<home id>/rooms/<room id>/memory/`: the paint, the floor and wall coverings,
and what runs behind the walls. It is there to find it again when a wall needs
touching up or a floor replacing. Every field is optional, and each has a help line
with an example.

| Field | Content |
| --- | --- |
| Paint colour, brand, reference, batch | As written on the tin; the batch matters because shades differ from one batch to another. |
| Paint left in stock | The tin left over, chosen among the items of the [stock](stock.md) of the home; the room page then shows its quantity and where it is kept. Add it to the stock first if it is not there. |
| Floor covering, wall covering | The product, with its make and reference if you know them. |
| Memory notes | What the walls and the floor hide, or anything else to remember. Free text, 4,000 characters at most. |

Before the stock was linked, this field was free text; it was kept, word for word, as a line
`Paint left in stock: ...` of the memory notes.

Photos of what is behind the walls are added from the [room page](room.md), with
the category **Behind the walls**.
