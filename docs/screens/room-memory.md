# Room memory

What was used and fitted in a room, at `/h/<home id>/rooms/<room id>/memory/`,
to find it again when a wall needs touching up or a floor replacing. Every field
is optional.

| Field | Content |
| --- | --- |
| Paint colour, brand, reference, batch | As written on the tin. |
| Paint left in stock | For example "half a tin, in the garage". |
| Floor covering, wall covering | The product, and where it was bought. |
| Memory notes | Free text, 4,000 characters at most. |

Photos of the open walls are added from the [room page](room.md).
