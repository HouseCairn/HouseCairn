# Contractor form

The form to add a contractor, at `/h/<home id>/contractors/new/`, and to edit one, at
`/h/<home id>/contractors/<contractor id>/edit/`. Only the **name** is required.

| Field | Content |
| --- | --- |
| Trade | One of the list: plumber, electrician, heating engineer, roofer, carpenter, painter, mason, gardener, locksmith, chimney sweep, or **Other**. |
| Which trade | Only with **Other**, and then required: the trade in your own words. |
| Phone | Digits, spaces and `+ ( ) - . /` only. |
| Email address | A valid address. |
| Address | Several lines are fine. |
| Note | Free text. |

A contractor can also be created from the [task form](task-form.md), by typing a new name in
its contractor field; the rest is added here afterwards.
