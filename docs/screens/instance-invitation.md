# Instance invitation

The page an invitation to the instance opens, at `/join/<link>/`. The link
comes by email from the administrator of the instance and invites you to
create an account, without any home: you create your first home afterwards.

- **No account yet**: choose a password and **Create the account**. The
  account takes the invited address, which the link has just proved.
- **An account already**: **Sign in**, then come back to the link and **Accept
  the invitation**. You can also continue with the instance's single sign-on,
  if the provider confirms the invited address.

The link works once. A link that was used, revoked, replaced by a newer one or
has expired opens a page saying it no longer works, without any detail: ask
the administrator to send it again. Opening links is limited per client
address.
