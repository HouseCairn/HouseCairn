# QR labels

The stickers of a home, at `/h/<home id>/labels/`, opened from the **QR labels** row of
the [home](home.md) page. It lists every room, item and stock item of the home, each
with a check box and the state of its label: a link to the label when it has one,
*No label yet* when it has not. A stock item is printed with its storage location where
an item is printed with its room.

- **Layout** is the format of the PDF: an **A4 sheet, 3 by 8 labels** (63.5 by 33.9 mm,
  the common size of adhesive sheets), or a **62 mm roll, one label per page** for a
  label printer of the Brother QL kind.
- **Print the labels** downloads the PDF of what is ticked, in the order of the list,
  up to 200 labels at a time. Each label carries the QR code, the name of the object and
  where it is. Members who may write get a label made for every ticked object that has
  none; a read-only member prints the labels that exist and is told so when a ticked
  object has none.

What a sticker opens, and how to set the address it holds, is in the
[guide](../guides/qr-labels.md). An address that belongs to a home you are
not a member of answers "Page not found", the same as one that does not exist.
