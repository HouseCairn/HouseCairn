# Sign-in

Sign in with the email address and password of a local account, with a
passkey, or through single sign-on when the instance has an OpenID Connect
provider ([Single sign-on](../administration/oidc.md)). A link to sign up
appears only when local sign-up is open (`HOUSECAIRN_SIGNUP_OPEN=true`).
