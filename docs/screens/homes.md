# Homes

The list of the homes you belong to, at `/h/`. Each name opens the page of
that home; **Add a home** creates a new one, and **Restore a home** makes a new
home from the archive of **Export all data** (see
[Export and deletion](../administration/data.md)). A home that requires signing in
through a provider you did not use in this session is marked, for example
"Company SSO required".
